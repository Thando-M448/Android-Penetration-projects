# Android-Penetration-projects
Android penetration testing project report and demonstrations (static &amp; dynamic analysis)
Android Penetration Testing Project  
Advanced School of Information Technology (ASIT)

   Overview  
Conducted a comprehensive penetration testing project on Android applications, focusing on both static and dynamic analysis. The project was part of my Security Administration and Computer Forensics program, designed to simulate real-world mobile security assessments in a controlled environment.

        Tools & Techniques Used

Static Analysis: APKTool, Dex2jar, JD-GUI, JADX

Device Interaction: Android Debug Bridge (ADB)

Dynamic Analysis: Drozer framework, Burp Suite proxy interception

Testing Environment: Genymotion emulator, rooted Android device

          Key Achievements

Decompiled APKs to inspect manifest files, Smali code, and hidden resources.

Identified insecure permissions, exported components, and weak cryptographic implementations.

Used Drozer to map attack surfaces, revealing exported activities, receivers, and providers.

Intercepted and manipulated insecure network traffic with Burp Suite.

Documented vulnerabilities and proposed mitigation strategies for secure app development.

         Outcome  
This project strengthened my expertise in mobile application security, forensic analysis, and ethical hacking workflows, preparing me to tackle real-world cybersecurity challenges in Android ecosystems.
